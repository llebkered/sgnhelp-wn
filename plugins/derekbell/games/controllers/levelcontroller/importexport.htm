Exported file: storage/app/levels-export.zip

To import, upload a levels-export.zip file and click Import Levels.

Import File Format:
The import file must be a ZIP archive containing a single levels.json file.

levels.json should be a JSON array of level objects. Each object should include the required fields for a level.

Sample levels.json: 
[
    {
        "episode_id": 1,
        "title": "Sample Level",
        "slug": "sample-level",
        "level_number": 1,
        "episode_number": 1,
        "youtube_id": "abc123defgh",
        "excerpt": "Short summary.",
        "description": "A sample level for import.",
        "is_published": true,
        "is_promoted": false,
        "sort_order": 1
    },
    {
        "episode_id": 2,
        "title": "Another Level",
        "slug": "another-level",
        "level_number": 2,
        "episode_number": 2,
        "youtube_id": "xyz987klmno",
        "excerpt": "Another summary.",
        "description": "Another example.",
        "is_published": false,
        "is_promoted": true,
        "sort_order": 2
    }
]
  • File type: ZIP archive (.zip)
  • Required file inside ZIP: levels.json
  • Format: JSON array of objects, one per level
  • Required fields: episode_id, title, slug, level_number, episode_number, youtube_id, excerpt, description, is_published, is_promoted, sort_order
