Create Episode from YouTube Playlist

Select a game and paste a YouTube playlist URL or ID. The episode title will be set from the playlist title and levels will be created as unpublished.

What will be created?

  • One new episode (unpublished) using the playlist title
  • A level for each playlist video (unpublished)
  • Levels will be numbered sequentially
  • Episode number will be auto-incremented
  • A maximum of levels will be imported per playlist
