Exported file: storage/app/episodes-export.zip

To import, upload a episodes-export.zip file and click Import Episodes.

Import File Format:
The import file must be a ZIP archive containing a single episodes.json file.

episodes.json should be a JSON array of episode objects. Each object should include the required fields for an episode.

Sample episodes.json: 
[
    {
        "game_id": 1,
        "title": "Sample Episode",
        "slug": "sample-episode",
        "episode_number": 1,
        "start_level": 1,
        "end_level": 10,
        "excerpt": "Short summary.",
        "description": "A sample episode for import.",
        "is_published": true,
        "is_promoted": false,
        "sort_order": 1
    },
    {
        "game_id": 2,
        "title": "Another Episode",
        "slug": "another-episode",
        "episode_number": 2,
        "start_level": 11,
        "end_level": 20,
        "excerpt": "Another summary.",
        "description": "Another example.",
        "is_published": false,
        "is_promoted": true,
        "sort_order": 2
    }
]
  • File type: ZIP archive (.zip)
  • Required file inside ZIP: episodes.json
  • Format: JSON array of objects, one per episode
  • Required fields: game_id, title, slug, episode_number, start_level, end_level, excerpt, description, is_published, is_promoted, sort_order
