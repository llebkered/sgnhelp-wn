Exported file: storage/app/games-export.zip

To import, upload a games-export.zip file and click Import.

Import File Format:
The import file must be a ZIP archive containing a single games.json file.

games.json should be a JSON array of game objects. Each object should include the required fields for a game.

Sample games.json: 
[
    {
        "title": "Sample Game",
        "slug": "sample-game",
        "excerpt": "Short summary.",
        "description": "A sample game for import.",
        "is_published": true,
        "is_promoted": false,
        "sort_order": 1,
        "color_theme": "blue"
    },
    {
        "title": "Another Game",
        "slug": "another-game",
        "excerpt": "Another summary.",
        "description": "Another example.",
        "is_published": false,
        "is_promoted": true,
        "sort_order": 2,
        "color_theme": "red"
    }
]
  • File type: ZIP archive (.zip)
  • Required file inside ZIP: games.json
  • Format: JSON array of objects, one per game
  • Required fields: title, slug, excerpt, description, is_published, is_promoted, sort_order, color_theme
